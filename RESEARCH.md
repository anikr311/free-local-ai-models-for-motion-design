**Runners explained (install these first):**
- **Pinokio — best overall installer for a non-coder designer.** Free, MIT-licensed, 1-click installs for ComfyUI, Ollama, Wan 2.1/2.2, HunyuanVideo, TTS apps etc.; isolates each app's Python/CUDA so installs don't clash. Guidance: ~6 GB VRAM for image, ~12 GB+ for video; NVIDIA safest. Caveat: community reports of Windows/Mac install freezes — treat as convenience, not pro infrastructure. Sources: https://www.aixploria.com/en/pinokio/ , https://thegtmdirectory.com/tools/pinokio
- **LM Studio — best for LLMs if you want a GUI.** Model browser + chat, no terminal; free for commercial use since July 2025 (app itself is closed-source); recommends 16 GB RAM / 4 GB VRAM minimum. **Ollama — best for LLMs if you want automation/API:** MIT, CLI + desktop app, one-command pulls (`ollama run qwen3:14b`), OpenAI-compatible local API that other tools can call. Same hardware physics — both wrap llama.cpp/GGUF. Sources: https://www.storagereview.com/best/local-llm-tools , https://www.guidetoartificialintelligence.com/en/learn/run-models-own-computer-2026/
- **ComfyUI — the only runner that matters for image + video.** Node-based, free/open-source; install it *through Pinokio* to skip manual Python/CUDA setup. Does not run in Ollama/LM Studio — diffusion models are a different world from LLMs. **Current versions (Oct 2026): ComfyUI 0.42.0, Ollama 0.40.x, LM Studio 0.4.28 — FLUX 3 Image [klein] needs ComfyUI 0.41+.**

**The three licence traps to memorise:**
1. **FLUX.1 [dev] ≠ FLUX.1 [schnell].** Dev = non-commercial weights (outputs usable commercially per BFL terms in some readings, but do not build a paid pipeline on it without a BFL licence — no public price). Schnell = Apache 2.0, fully commercial. Same trap, new generation: **FLUX 3 Image [klein] is NOT Apache 2.0** — Kommunity Licence, free commercial only under US$5M annual revenue; **FLUX.2 [klein] 9B and FLUX.2 [dev] 32B are non-commercial** (only the 4B klein is Apache 2.0).
2. **XTTS-v2, F5-TTS, Fish Speech open weights = NON-commercial** (see Stage 2), and Coqui is dead so no XTTS licence can be bought.
3. **"Community licence" ≠ Apache.** Llama, Gemma 3, HunyuanVideo, LTX-2.x, CogVideoX-5B all allow *this* user's commercial use with conditions (user caps / revenue caps / territory exclusions) — fine for a solo designer in Bangladesh, but read the clause.
4. **Newer ≠ same licence.** **Qwen-Image-2.1 (Sep 2026) is NON-commercial** (Qwen Research License) — do not confuse it with the Apache-2.0 Qwen-Image 20B line (now Qwen-Image-2512). **Qwen3.8-Max / Qwen3.8-Flash-Next use custom Qwen licences, not Apache 2.0** — only Qwen3.8-27B is Apache 2.0.

### 4. Final Output — LOCAL VIDEO MODELS (via ComfyUI) + After Effects
