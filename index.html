RAM + VRAM

তোমার RAM আর VRAM অনুযায়ী কোনটা চলবে?

এবার দুটো আলাদা selector — উপরে system RAM (8 / 16 / 32 / 64 GB), নিচে GPU VRAM (8 / 12 / 16 / 24 GB), ঠিক RAM-এর মতোই। দুটো মিলিয়ে দেখো, কারণ দুটো আলাদা জিনিস: RAM ঠিক করে কত বড় মডেল load হবে, offload কতটা smooth হবে, আর LM Studio + ComfyUI + Premiere একসঙ্গে খোলা যাবে কিনা; image/video মডেলের আসল gate হলো GPU-র VRAM। Research-এর ভাষায় GPU কিনতে হলে এখনো 24 GB VRAM (RTX 3090 / 4090)-ই sweet spot, আর RAM-এর sweet spot হলো 32 GB।

Licence Traps — এই ৪টা মুখস্থ রাখো

Licence গুলো এই research-এর summary — legal advice না। তুমি যে exact checkpoint download করবে, তার model card নিজে পড়ো; এই market-এর #1 trap-ই হলো code licence ≠ weights licence।

Trap 1 — FLUX.1 [dev] ≠ FLUX.1 [schnell]. Dev = non-commercial weights (কিছু reading-এ output commercial usable হলেও, BFL licence ছাড়া paid pipeline dev-এর ওপর বানিও না — public price নেই)। Schnell = Apache 2.0, fully commercial। Client work-এ schnell/SDXL-ই safe।
Trap 2 — XTTS-v2, F5-TTS, Fish Speech-এর open weights = NON-commercial। Quality যতই ভালো হোক, paid client work-এ legally ব্যবহার করা যাবে না। আর Coqui মৃত — XTTS-এর licence কেনার উপায়ও নেই।
Trap 3 — "Community licence" ≠ Apache। Llama, Gemma 3, HunyuanVideo, LTX-2.x, CogVideoX-5B সবই শর্ত সাপেক্ষে commercial use দেয় (user cap / revenue cap / territory exclusion)। Bangladesh-এর solo designer হিসেবে তুমি fine — তবু clause টা পড়ে নাও। একই কথা নতুনগুলোতেও: FLUX 3 Image [klein]-এর Kommunity License = commercial use শুধু US$5M annual revenue-র নিচে; Kitten TTS 2-র Stellon Labs Community License-ও Apache 2.0 না।
Trap 4 (নতুন) — Qwen-Image-2.1 আর FLUX.2-র বড় ভার্সন = NON-commercial। Qwen-Image-2.1 (Sep 2026) ও এর Turbo checkpoint Qwen Research License-এ — client work-এ কখনো না; commercial-safe Qwen-Image line এখনো 20B মডেলটাই, বর্তমান update Qwen-Image-2512 (Dec 2025, Apache 2.0)। তেমনি FLUX.2 [klein] 9B আর FLUX.2 [dev] 32B non-commercial — FLUX.2 family-তে শুধু 4B klein-টাই Apache 2.0।
