RAM + VRAM

তোমার RAM আর VRAM অনুযায়ী কোনটা চলবে?

এবার দুটো আলাদা selector — উপরে system RAM (8 / 16 / 32 / 64 GB), নিচে GPU VRAM (8 / 12 / 16 / 24 GB), ঠিক RAM-এর মতোই। দুটো মিলিয়ে দেখো, কারণ দুটো আলাদা জিনিস: RAM ঠিক করে কত বড় মডেল load হবে, offload কতটা smooth হবে, আর LM Studio + ComfyUI + Premiere একসঙ্গে খোলা যাবে কিনা; image/video মডেলের আসল gate হলো GPU-র VRAM। Research-এর ভাষায় GPU কিনতে হলে এখনো 24 GB VRAM (RTX 3090 / 4090)-ই sweet spot, আর RAM-এর sweet spot হলো 32 GB।

Recommended End-to-End Local Pipeline

সব মিলিয়ে একটা $0 workflow — আসল খরচ শুধু 12–24 GB NVIDIA GPU আর generation time।

1
Setup — Pinokio

Pinokio ইন্সটল করে তার ভেতর থেকে LM Studio আর ComfyUI বসাও। বাকি সব এর পর।

2
Idea + Script — LM Studio · Qwen3-14B

Hook, story, 60s script (~130–160 words), shot list। Temperature 0.9–1.1-তে creative draft। 24 GB card থাকলে step-up: Qwen3.8-27B।

3
Voice — Qwen3-TTS / Maya 2 Native / ZONOS3-Mini / Kokoro / Piper

English final VO: Qwen3-TTS 1.7B (3-second voice clone সহ; Chatterbox retire হয়েছে — 4 Nov 2026)। Scratch/timing: Kokoro। Bangla: candidates এখন TWO — Maya 2 Native (~12 GB VRAM) আর ZONOS3-Mini (CPU, GPU লাগে না) — দুটোকেই final-এর আগে আসল Bangla script-এ test করো; timing draft-এর CPU fallback Piper bn_BD (শুধু drafts), না হলে cloud/human (নিচে Cloud Fallback দেখো)।

4
Storyboard — ComfyUI · Qwen-Image-Edit + FLUX 3 klein

Text/product frame-এ Qwen-Image, photoreal frame-এ FLUX 3 Image [klein] (Kommunity licence-র US$5M cap মাথায় রেখে; fully Apache fallback FLUX.1-schnell), fast photoreal-এ Z-Image Turbo। Consistency: LoRA + ControlNet + IP-Adapter + fixed seed। Board ও client comments: Figma। বাংলা type এখানেই আসল text layer হিসেবে বসবে।

5
Animate — ComfyUI · Wan 2.2 I2V

Storyboard frame গুলোই first frame — 5s করে hero insert, product move, background generate করো। Speed লাগলে LTX। Finish-এ RelayVSR (ComfyUI 0.45.0+, Apache-2.0) দিয়ে 2x/4x upscale করো।

6
Finish — Premiere + After Effects

Assemble, titles, Bangla type, grade, sound mix। Timeline-এর gap-এ Adobe-র in-timeline generative tool — শুধু দরকার হলে। Social cut-down একই Figma/ComfyUI asset থেকে।

একটাই cloud sub যোগ করো — শুধু যখন লাগবে: Google AI Pro $19.99/mo (Veo + Nano Banana + Gemini polish + Bangla-capable Gemini TTS unlock হয়) অথবা Bangla-heavy মাসে ElevenLabs Creator $22/mo। দুটো একসঙ্গে নয়।

Licence Traps — এই ৪টা মুখস্থ রাখো

Licence গুলো এই research-এর summary — legal advice না। তুমি যে exact checkpoint download করবে, তার model card নিজে পড়ো; এই market-এর #1 trap-ই হলো code licence ≠ weights licence।

Trap 1 — FLUX.1 [dev] ≠ FLUX.1 [schnell]. Dev = non-commercial weights (কিছু reading-এ output commercial usable হলেও, BFL licence ছাড়া paid pipeline dev-এর ওপর বানিও না — public price নেই)। Schnell = Apache 2.0, fully commercial। Client work-এ schnell/SDXL-ই safe।
Trap 2 — XTTS-v2, F5-TTS, Fish Speech (S1/S2)-এর open weights = NON-commercial। Quality যতই ভালো হোক, paid client work-এ legally ব্যবহার করা যাবে না। আর Coqui মৃত — XTTS-এর licence কেনার উপায়ও নেই।
Trap 3 — "Community licence" ≠ Apache। Llama, Gemma 3, HunyuanVideo, LTX-2.x, CogVideoX-5B সবই শর্ত সাপেক্ষে commercial use দেয় (user cap / revenue cap / territory exclusion)। Bangladesh-এর solo designer হিসেবে তুমি fine — তবু clause টা পড়ে নাও। একই কথা নতুনগুলোতেও: FLUX 3 Image [klein]-এর Kommunity License = commercial use শুধু US$5M annual revenue-র নিচে; Kitten TTS 2-র Stellon Labs Community License-ও Apache 2.0 না। আর নতুন Fish Audio Drama 3-র Community License v1.0 = free commercial use শুধু US$500k annual revenue-র নিচে (hosted TTS/cloning service-এর জন্য আলাদা licence)। নতুন MiniMax H3-Image-র MiniMax Community License = Bangladesh-এ commercial allowed, কিন্তু US, EU, UK, South Korea excluded আর US$1M annual revenue-র উপরে prior written authorisation লাগবে।
Trap 4 (নতুন) — Qwen-Image-2.1 আর FLUX.2-র বড় ভার্সন = NON-commercial। Qwen-Image-2.1 (Sep 2026) ও এর Turbo checkpoint Qwen Research License-এ — client work-এ কখনো না; commercial-safe Qwen-Image line এখনো 20B মডেলটাই, বর্তমান update Qwen-Image-2512 (Dec 2025, Apache 2.0)। তেমনি FLUX.2 [klein] 9B আর FLUX.2 [dev] 32B non-commercial — FLUX.2 family-তে শুধু 4B klein-টাই Apache 2.0।

Cloud Fallback — শুধু Brief

ChatGPT Plus $20 · Claude Pro $20 ($17 annual) · Google AI Pro $19.99। 2026 reviews-এ Claude #1 natural, least-AI-sounding prose-তে; GPT-5.x research+structure-এ সেরা; Gemini per-token সবচেয়ে সস্তা আর bundle value সেরা — Flow/Veo + Nano Banana unlock হয় বলে এই designer-এর জন্য সেরা single $20 arguably Gemini, যদিও লেখায় Claude এগিয়ে।
